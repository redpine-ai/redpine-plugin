# Redpine Connect

This repo is a Claude Code plugin. If you are not Claude Code, the parts that matter are:

- `plugins/redpine/skills/redpine-search/SKILL.md`: how to use the Redpine Connect MCP server. Read it before calling any Redpine tool.
- `plugins/redpine/skills/redpine-search/references/`: billing, search filters, query craft, troubleshooting.
- `plugins/redpine/.mcp.json`: the hosted server, `https://api.redpine.ai/mcp`.

Register the MCP server in your own client config (see README, "Other agents"), then follow SKILL.md.
